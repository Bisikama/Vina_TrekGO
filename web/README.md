# TREKKING FRONTEND

Dự án Frontend cho hệ thống TREKKING, xây dựng trên nền tảng **Next.js (App Router)** với kiến trúc **Feature-Based Architecture**.

## 📖 Tài liệu Hướng dẫn Dev mới (Onboarding Guide)
Vui lòng đọc kỹ file [ARCHITECTURE.md](./ARCHITECTURE.md) trước khi bắt đầu viết code để nắm rõ các quy tắc:
- Cấu trúc thư mục Feature-Based
- Quy tắc Named Export (`export const ...`)
- Quy tắc Public API (`index.ts`)
- Quy trình 7 bước tạo một Feature mới

## 🚀 Khởi chạy dự án

```bash
# Cài đặt dependencies
npm install

# Khởi chạy môi trường Dev
npm run dev

# Kiểm tra Build & Typecheck
npm run build
```
